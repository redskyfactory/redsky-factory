# Redsky Factory

Redsky Factory의 Android 앱을 소개하는 정적 웹사이트입니다.

## 파일 구성

- `index.html`: 사이트 전체 코드
- `README.md`: 프로젝트 및 배포 안내
- `.gitignore`: Git에서 제외할 로컬 파일 목록

별도의 설치나 빌드 과정 없이 `index.html`을 브라우저에서 열어 확인할 수 있습니다.

## Cloudflare Pages 배포

GitHub 저장소에 이 폴더의 파일을 올린 후 Cloudflare Pages에서 저장소를 연결합니다.

- Framework preset: `None`
- Build command: 비워 두기
- Build output directory: `/`
- Root directory: `/`

## 게시 전 확인

- `contact@redskyfactory.com` 메일 주소
- MelodyWave와 OnePic의 개발 상태 및 기능 설명
- 출시 후 Google Play 링크
- 개인정보 처리방침 및 이용약관 페이지

현재 사이트에는 방문자 분석, 광고 또는 추적 스크립트가 포함되어 있지 않습니다.
